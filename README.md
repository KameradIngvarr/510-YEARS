# 510 years

Интерактивный 3D-компаньон рабочего стола Windows во вселенной **Fallout** (Анклав) на базе **Electron** и **Three.js**.

На панели задач поселяется боец Анклава в силовой броне с аутентичными скелетными анимациями (`.kf`), оригинальным оружием, озвучкой и летающим спутником-робоглазом (Eyebot), транслирующим Радио Анклава.

---

## Возможности

### 3D-модели и анимации
- **3 модели силовой брони** (переключаются из контекстного меню / трея):
  - **Броня Оставшихся (FNV)** (`remnants`)
  - **Броня Гэннонов Тесла (FNV)** (`gannon`)
  - **Броня Анклава Mk II (FO3)** (`enclave_fo3`)
- **3 вида оружия** с индивидуальными визуальными эффектами, очередями и звуками:
  - **Гаусс-винтовка** — одиночный мощный выстрел с голубым лучом и ударным кольцом
  - **Лазерная винтовка** — очереди по 3–4 выстрела с красными лазерными импульсами
  - **Плазменная винтовка** — очереди по 2–3 выстрела с зелёными плазменными сгустками
- **Оригинальные скелетные анимации Fallout: New Vegas** (`.kf`): покой, ходьба и патрулирование по панели задач, стрельба, осмотр оружия, сканирование, воинское приветствие, перетаскивание мышью и режим сна.
- **Спутник-робоглаз (Eyebot)**: парит рядом с солдатом и проигрывает речи президента Эдема, монологи и музыку Радио Анклава.

### Озвучка, реплики и аудио
- **Режимы озвучки солдата**:
  - *Архи-сержант Дорнан (Полный)*
  - *Часовой / Связь (Наварро и Гекко)*
- **Диалоговые окна с автоперелистыванием**: длинные реплики аккуратно разбиваются на страницы и не обрываются при появлении новых.
- **Фразы перед расстрелом**: особые реплики приводят к немедленному выстрелу по завершении фразы.
- **Раздельные и общий регуляторы громкости**:
  - Общая громкость (`Master`)
  - Громкость речи солдата
  - Громкость радио / Робоглаза
  - Громкость эффектов (выстрелы, шаги, сервоприводы)
- **Синхронизация речи**: реплики солдата и трансляции президента на радио не перекрывают друг друга при автоматическом воспроизведении.

### Поведение и настройки
- Прозрачное окно поверх остальных окон (`alwaysOnTop`), не перехватывающее клики мимо модели.
- Свободное перетаскивание бойца по экрану, автоматическое патрулирование вдоль панели задач и возврат на панель задач через меню.
- Настройки (выбранная броня, оружие, громкость, масштаб, режим речи, автозапуск и др.) сохраняются автоматически.
- Поддержка автозапуска вместе с Windows.

---

## Управление

- **ЛКМ по солдату** — случайная реплика / реакция (при перетаскивании — перемещение по экрану).
- **ПКМ по солдату или иконке в трее** — контекстное меню:
  - выбор модели брони и оружия;
  - выбор режима озвучки и настройка громкости;
  - выстрел из оружия, воинское приветствие, радиосообщение Анклава, следующий трек радио;
  - режим сна, патрулирование, масштаб, возврат на панель задач, автозапуск.

## Структура проекта

```text
510 years/
├── package.json                # Манифест приложения и зависимости (Electron, Three.js)
├── assets/                     # 3D-модели (.glb), текстуры и аудио (.wav / .mp3)
└── src/
    ├── main.js                 # Главный процесс Electron: окно, трей, IPC, сохранение настроек
    ├── preload.js              # Безопасный мост IPC (contextBridge)
    ├── index.html              # Разметка оверлея и диалоговых окон
    ├── renderer.js             # Сцена Three.js, VFX выстрелов, логика поведения и UI
    ├── animator.js             # Микшер анимаций, процедурные довороты и цикл стрельбы
    ├── rigBuilder.js           # Сборка ригов брони, оружия, Робоглаза и точек дула
    ├── audioEngine.js          # Воспроизведение речи, радио и звуковых эффектов
    ├── dornanPhrases.js        # База реплик сержанта Дорнана
    ├── enclaveOutpostPhrases.js# Реплики часового и связистов (Наварро / Гекко)
    └── enclaveRadioData.js     # Записи Радио Анклава (речи Эдема и музыка)
```
